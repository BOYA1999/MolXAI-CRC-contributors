# Release privacy statement

This package was assembled from an explicit allowlist and independently scanned before archiving. It intentionally excludes manuscript and supplementary text, publication tables, captions, figures, figure-generation scripts, author names, affiliations, email addresses, account names, local absolute paths, document comments, tracked changes, caches, logs, model weights, raw molecule tables, and bundled third-party source trees.

The archive should be re-scanned after any author metadata, repository URL, citation record, or paper-facing material is added at the post-review unblinding stage.
